# Data directory

Raw Autonomous Greenhouse Challenge data are intentionally not stored in this public repository.

- Place authorized local source data under `data/raw/` or beside the notebook as `agc2_data/`.
- `data/raw/` and `agc2_data/` are ignored by Git.
- `sample/live_packet_example.csv` is a schema/example only and is not part of the paper's quantitative evaluation.

Official dataset DOI: `10.4121/uuid:88d22c60-21b3-4ea8-90db-20249a5be2a7`.
