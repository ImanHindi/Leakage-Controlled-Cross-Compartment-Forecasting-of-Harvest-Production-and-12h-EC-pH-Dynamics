# Data directory

Only a small synthetic schema example is distributed in `sample/`.
The full Autonomous Greenhouse Challenge, Second Edition dataset is not
redistributed in this repository.

Obtain the original dataset from its authorized source using DOI:
`10.4121/uuid:88d22c60-21b3-4ea8-90db-20249a5be2a7`.

Place authorized local copies under `data/raw/`. That directory is excluded by
`.gitignore`. Generated manuscript figures, tables, and prediction files are
stored under `outputs/`.
