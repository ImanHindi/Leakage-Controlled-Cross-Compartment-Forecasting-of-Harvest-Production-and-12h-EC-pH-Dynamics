# Data Availability

The full **Autonomous Greenhouse Challenge, Second Edition (2019)** dataset is
not redistributed through this repository. The dataset should be obtained from
its authorized source under the applicable terms of use.

**Dataset identifier:**  
`10.4121/uuid:88d22c60-21b3-4ea8-90db-20249a5be2a7`

After obtaining the dataset, place the authorized files locally under:

```text
data/raw/
```

The `data/raw/` directory is excluded from Git tracking to prevent accidental
redistribution of the source data.

## Expected input variables

The main training workflow uses the following greenhouse variables:

- `Tair` — air temperature;
- `Rhair` — relative humidity;
- `CO2air` — air carbon-dioxide concentration;
- `Tot_PAR` — total photosynthetically active radiation;
- `EC_drain_PC` — drain electrical conductivity;
- `pH_drain_PC` — drain pH;
- `Cum_irr` — cumulative irrigation.

Additional engineered variables, lagged values, rolling statistics, temporal
features, and harvest-related variables are generated by the training notebook
as described in the accompanying paper and repository documentation.

## Reproducibility

To reproduce the reported analysis:

1. Obtain the original dataset from its authorized source.
2. Place the files under `data/raw/`.
3. Create the required Python environment using `requirements.txt`.
4. Open the notebook in `training/`.
5. Verify the configured data paths and team names.
6. Run all notebook cells in order.

The notebook documents the main preprocessing, quality-control, temporal
feature-engineering, chronological splitting, model-training, and evaluation
steps.
